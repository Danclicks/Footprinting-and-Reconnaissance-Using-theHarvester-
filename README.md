# Footprinting-and-Reconnaissance-Using-theHarvester-
Penetrating Testing Email and Subdomain 

A practical cybersecurity internship exercise using theHarvester in Kali Linux to gather publicly available information associated with Microsoft.com.

Tasks Performed
- Email and subdomain enumeration using Baidu (limit: 1,000).
- Email and subdomain enumeration using all supported sources (limit: 50).

Skills Practised
- Open-Source Intelligence (OSINT).
- Email enumeration.
- Subdomain discovery.
- Digital footprint analysis.
- Kali Linux command-line operations.

Purpose: To understand how publicly available information can be gathered and analysed during cybersecurity reconnaissance.
